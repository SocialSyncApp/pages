02

Données collectées

2.1 Données traitées localement (non transmises à Relay)

Les données suivantes sont exclusivement stockées sur votre appareil et ne sont jamais transmises à nos serveurs :

  • Contenus de vos posts, brouillons et médias
  • Tokens d'authentification OAuth des plateformes sociales (stockés chiffrés via Windows DPAPI)
  • Données analytiques récupérées depuis les plateformes sociales
  • Paramètres et préférences de l'application
  • Base de données SQLite locale (posts planifiés, historique, médias)

05

Stockage et sécurité des données

5.1 Données locales (sur votre appareil)

  • Base de données SQLite stockée dans %AppData%\Roaming\Relay
  • Tokens OAuth chiffrés via Windows DPAPI (Credential Manager), jamais en clair
  • Cache médias dans le répertoire AppData, taille configurable par l'utilisateur

5.2 Données côté serveur Relay

  • Serveurs hébergés sur infrastructure cloud sécurisée
  • Chiffrement au repos et en transit (TLS 1.2+ exclusivement)
  • Certificate pinning pour les communications entre l'application et le backend IA
  • Clés API tierces (LLM) stockées côté serveur uniquement, jamais exposées au client
  • Accès restreint aux personnels autorisés avec journalisation des accès

5.3 Mesures organisationnelles

  • Aucun contenu de post ou token OAuth n'est loggé côté serveur
  • Logs d'erreurs anonymisés — sans identifiant personnel
  • Possibilité de désactiver totalement l'envoi de logs depuis les paramètres de l'application
  • Packages de mise à jour signés numériquement, intégrité vérifiée avant installation
06

Partage avec des tiers

Relay ne vend, ne loue ni ne cède vos données personnelles à des tiers à des fins commerciales. Des données peuvent être partagées uniquement dans les cas suivants :

TiersDonnées partagéesRaison
Anthropic / OpenAI (LLM) Texte soumis pour génération IA Fourniture du module IA Premium — via proxy sécurisé Relay
Prestataire de paiement (ex. Stripe, Paddle) Données de paiement, e-mail Traitement des transactions — certifié PCI-DSS
Hébergeur cloud Données de licence (chiffrées) Infrastructure du backend Relay
Autorités légales Données requises par réquisition judiciaire Obligation légale
Plateformes sociales : Vos publications sont transmises directement depuis votre appareil aux APIs des plateformes (Meta, LinkedIn, X, TikTok) via vos propres tokens OAuth. Relay n'est pas intermédiaire de ces données de contenu.
07

Transferts de données

Dans le cadre du module IA, les textes soumis transitent par notre backend avant d'être transmis à des fournisseurs LLM (Anthropic, OpenAI).

Ces transferts sont encadrés par :

  • Les clauses contractuelles types applicables
  • Les certifications et garanties des sous-traitants (DPA signés)
  • Les mécanismes de minimisation des données (seul le texte nécessaire est transmis, sans identifiant personnel direct)

10

Cookies et traceurs

L'application Relay (Windows Desktop) n'utilise pas de cookies.

En ce qui concerne le site web de présentation de Relay, les cookies utilisés se limitent à :

  • Cookies strictement nécessaires : gestion de session, préférences de langue — aucun consentement requis.
  • Cookies analytiques : uniquement avec votre consentement explicite, collecte anonymisée (aucun identifiant croisé avec des tiers).

Aucun cookie publicitaire ou de tracking tiers n'est utilisé sur nos supports.
